Definitions

The four definitions in Theorem A, with their exact Lean expressions.

  • Algebraic character
  • Submultiplicative seminorm
  • Local multiplicative convexity
  • Boundedness on bounded sets

The definitions share a commutative ring A, possibly without an identity, and a complex vector-space structure:

variable (A : Type u) [NonUnitalCommRing A] [Module ℂ A]

The last two definitions also use [TopologicalSpace A]. The complete file includes the imports, namespace and shared declarations.

Algebraic character

A character is a nonzero complex-linear multiplicative map \chi\colon A\to\mathbb C.

\chi(xy)=\chi(x)\chi(y),\qquad\chi(cx+dy)=c\chi(x)+d\chi(y).

Continuity is not part of this definition.

Project abbreviation using Mathlib’s nonunital algebra homomorphisms.

Exact Lean definitionSource · 
abbrev Character := {χ : A →ₙₐ[ℂ] ℂ // χ ≠ 0}
Explain this Lean definition

A character combines an algebraic homomorphism with the condition that it is not the zero map.

The zero map would itself be bounded on every set, but it is excluded from the definition of character.
For an algebra with an identity, a nonzero multiplicative complex-linear map to ℂ necessarily sends the identity to 1. Requiring a unit is unnecessary here.
Submultiplicative seminorm
A complex seminorm p is submultiplicative when
p(xy)\leq p(x)p(y)\qquad(x,y\in A).
No normalisation at the identity is required.
Project definition, using Mathlib’s complex seminorms.
Exact Lean definitionSource · 
def IsSubmultiplicative (p : Seminorm ℂ A) : Prop :=
  ∀ x y : A, p (x * y) ≤ p x * p y
Explain this Lean definition
Submultiplicativity is the additional inequality that links a seminorm to multiplication.
The zero seminorm is allowed. Hausdorffness is required of the topology generated by the whole family, not of each seminorm separately.
Local multiplicative convexity
The topology of A is generated by a family of submultiplicative complex seminorms.
The family may be uncountable. The topology generated by it is the same topology used in the completeness and Hausdorff hypotheses.
Project definition, using Mathlib’s WithSeminorms.
Exact Lean definitionSource · 
def IsLocallyMultiplicativelyConvex : Prop :=
  ∃ P : Set (Seminorm ℂ A),
    (∀ p ∈ P, IsSubmultiplicative A p) ∧
    WithSeminorms (fun p : P => p.val)
Explain this Lean definition
The existing topology must be exactly the topology generated by a suitable family of submultiplicative seminorms.
Because the topology comes from complex seminorms, scalar multiplication has the usual continuity. Submultiplicativity gives continuity of multiplication.
Hausdorffness is a separate hypothesis of Theorem A. Together with WithSeminorms it means the family separates distinct elements.
An empty family generates the indiscrete topology. Under the theorem's Hausdorff hypothesis this can occur only for a one-element algebra.
Boundedness on bounded sets
Every bounded subset B has a finite bound on the moduli of its images:
\exists C\geq0\quad\forall a\in B,\quad|\chi(a)|\leq C.
The same C works for all a\in B; it may depend on \chi and B.
Project definition, using Mathlib’s von Neumann boundedness.
Exact Lean definitionSource · 
def BoundedOnBoundedSets (χ : A → ℂ) : Prop :=
  ∀ B : Set A, Bornology.IsVonNBounded ℂ B →
    ∃ C : ℝ, 0 ≤ C ∧ ∀ a ∈ B, ‖χ a‖ ≤ C
Explain this Lean definition
For each bounded subset, the character has one finite bound valid at every point of that subset.
For the empty set, C = 0 works.
No bound is required on the whole algebra unless the whole algebra is itself a bounded set.
This conclusion alone is not phrased as continuity. The metrisable continuity corollary is a separate consequence.
Standard notions used in the statement
These notions come from Mathlib. The four definitions above belong to this project.
Complex seminorm
A seminorm is a nonnegative real-valued function satisfying the triangle inequality and p(cx)=|c|p(x). It may vanish at a nonzero vector.
A topology generated by seminorms
WithSeminorms identifies the given topology with the one generated by the family. A basic neighbourhood of zero restricts finitely many seminorms at a time.
Bounded subset
A subset is von Neumann bounded if every neighbourhood of zero absorbs it. In the present setting, this is equivalent to boundedness in every defining seminorm. The bound may depend on the seminorm.
Completeness
Every Cauchy filter converges in the additive uniformity. The theorem is not restricted to metric spaces or to Cauchy sequences.
Hausdorff topology
Distinct points have disjoint neighbourhoods. Lean writes this separation condition as T2Space A.
Reading the notation
∀ means “for every”; ∃ means “there exists”; ∧ joins two conditions. Between propositions, → means implication. Prop is the type of propositions. Square brackets record mathematical structures and their compatibility.
