Scope and reproduction

The pinned Lean compiler and its bundled libraries were retained for compilation. Their imported declarations were included in the kernel replay. This run rebuilt the libraries required by the proof; it did not rebuild Lean itself or unrelated library modules.

The official checker uses Lean’s own kernel. It omits unsafe and partial implementation declarations. The project contains five partial compiler-generated recursion helpers; all project declarations passed the separate axiom audit. Theorem A is a safe, nonpartial theorem.

The original records are preserved. The downloadable copies replace private file locations with logical directory names and record both original and download hashes.

Relation to the paper

The Lean proof establishes the coordinate-flag approximation needed for Theorem A by a specialised argument. It uses polynomial approximation on compact convex sets, holomorphic families, additive contour splitting, and a finite sequence of coordinate cuts.

The general Oka theorems cited in the manuscript are not formalised here. The remaining algebraic argument and the reduction to algebras without an identity conclude the same Theorem A. Corollary B is not separately formalised.
